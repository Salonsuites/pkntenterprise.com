# pkntenterprise.com (bare domain)

Static mirror of the PKNT ENTERPRISES LLC company site, served on the bare domain by GitHub Pages
(Wix-registered domains cannot move their nameservers, so Cloudflare Pages cannot take the apex).
www.pkntenterprise.com is served by Cloudflare Pages from `Salonsuites/pknt-enterprise-site`;
this repo mirrors its `public/` folder. Change the source repo first, then copy here.
